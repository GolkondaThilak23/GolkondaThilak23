### 🥈 [HematoVision-Advanced-Blood-Cell-Classification-Using-Transfer-Learning](https://github.com/GolkondaThilak23/HematoVision-/tree/main)
> **To develop an AI-based system that detects and classifies blood cells using image classification via a pretrained MobileNetV2 model. The goal is to assist healthcare workers and researchers in identifying blood cell types for improved medical diagnostics.**

- 🔧 **Tech:** Python,Jupyter Notebook,Pandas,Flash
- The HematoVision project successfully demonstrates an AI-powered system for blood cell classification using transfer learning.
-  A pre-trained MobileNetV2 model enables accurate classification of eosinophils, lymphocytes, monocytes, and neutrophils from uploaded images.
-   The web app, developed using Flask, provides a simple interface for uploading images and viewing results in real time. The system is designed to be efficient, easy to use, and runs entirely on local machines.
